Sync Gmail

This page must be served at http://localhost:3000/admin.html — OAuth will fail with a redirect_uri_mismatch otherwise. Run python -m http.server 3000 from the project folder and open that exact URL.

Your session is managed via a refresh token — sign-in is automatic. If sync fails with an auth error, click "Get Sign-In Link" to re-authorize.

Preview & Publish

Two ways to share:
Save Locally stores events in this browser's localStorage — only visible on this device. Use it to preview on this machine.
Download JSON exports a timetable-data.json file. Replace that file wherever you've deployed the public page (e.g. GitHub Pages, Netlify) — that's what actually makes it visible to others.
